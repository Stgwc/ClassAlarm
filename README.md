# 网课闹钟（ClassAlarm）

桌面常驻的网课上下课倒计时小窗。矩形窗口、可拖动、贴边吸附、始终置顶，到点播放铃声。

## 功能

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 移动窗口，靠近屏幕四边会自动吸附贴边，位置自动记住 |
| 左上角图标 | 点击打开菜单，悬停有高亮效果 |
| 右上角 × | 直接关闭程序 |
| 显示 | 上课中显示「距离下课」，休息/假期显示「距离上课」；标题栏显示天气，底部显示今日课表进度 |

## 主题

- 内置 **深色 / 浅色 / 海蓝** 三种主题
- 设置 → 自定义主题：调主体色、线条色、圆点色、时间颜色、圆点大小，命名后「添加为自定义主题」，会出现在「换主题」菜单里
- 每个主题独立保存自己的设置，切换互不影响

## 显示设置

- **窗口大小**：小（280×132）/ 标准（320×150）/ 大（380×178）/ 特大（440×206）
- 人物位置、显示圆点、显示关闭按钮、显示天气开关

## 课表 / 课程 / 铃声

- **课表**：添加上课时段（滚轮选时/分，保存时自动排序、检查结束晚于开始、时段不重叠）、放假日期、常规循环
- **课程**：给每个时段选择学段和科目（含「无」「自习」），和课表自动对应
- **铃声**：选择音频文件后拖动轨道上两个滑块圈选片段；可保存多个铃声，上课铃/下课铃分别选择

## 天气

标题栏显示天气和明日预报，留空按网络 IP 定位，也可在设置里填写城市。

## 检查更新

右键菜单 →「检查更新…」，发现新版会提示下载并自动替换。

## 启动

- 双击 `ClassAlarm.exe` 即可运行，不需要安装 Python。
- 程序常驻、不占任务栏；在窗口上**右键**打开菜单。
- 课表、课程、铃声、主题等设置保存在同目录的 `config.json`。

## 常见问题

- **窗口不见了**：可能在屏幕边缘；删除 `config.json` 里的 `window` 后重启会回到默认位置。
- **没有声音**：确认菜单里没有开「关闭音效」；默认铃声是内置卡农，不需要文件。
- **提示「暂无课表」**：去设置 → 课表里添加上课时段，保存即可。
