# 网课闹钟（ClassAlarm） v0.15

桌面常驻的网课上下课倒计时小窗。矩形窗口、可拖动、贴边吸附、始终置顶，到点播放铃声。

## 两个版本

- **标准版**：只带「深色 / 浅色 / 海蓝」三种基础主题（含自定义主题功能），界面干净轻量
- **个人版**：包含全部主题（大肥鱼、丛雨、芳乃等）与全部功能

两个版本默认都是**浅色**主题；分发版配置已归零（无课表、无课程、天气清空，只保留默认卡农铃声）。

## 检查更新

菜单 →「检查更新…」会读取配置里的 `update_url`（一个返回 JSON 的地址，格式：
`{"version": "v0.16", "url": "https://…/ClassAlarm.exe"}`）。
有新版会提示下载并自动替换 exe 重启；`update_url` 为空时提示未配置。

## 启动

- 双击桌面「网课闹钟」快捷方式，或双击本目录 `run.bat`。
- 程序常驻，不会出现在任务栏；在窗口上**右键**可操作菜单。

## 功能

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 移动窗口，靠近屏幕四边会自动吸附贴边，位置自动记住 |
| 左上角图标 | 动漫主题显示专属图案（铁盆/武士刀/小刀），点击打开菜单；经典主题为圆点，悬停有高亮圈 |
| 右上角 × | 直接关闭程序（鼠标移上去会变红） |
| 显示 | 上课中显示「距离下课」，休息/假期显示「距离上课」；右上角显示下一节课时间（跨天标「明天」）；底部显示今日天气和明天预报 |

## 编辑课表

菜单 →「编辑课表…」打开编辑窗，直接按行修改：

- **每日上课时段**：每行 `开始-结束 名称`，例如 `07:40-11:30 上午`
- **放假**：每行 `开始 ~ 结束 备注`，例如 `2026-11-13 14:00 ~ 2026-11-15 12:00 周末假`
- **常规循环**：锚点（恢复上课时刻）、上课天数、放假天数

点「保存并生效」立即写入 `config.json` 并刷新倒计时，不需要重启。

## 设置

菜单 →「设置…」是统一设置面板，左侧分类：

- **自定义主题**（主题 + 窗口与人物合并）
  - 顶部「▶ 特殊选项」：点开才显示圆点图案、接触图案、背景图、左侧图案、人物位置、显示开关
  - 下方「颜色」：主体/线条/圆点/时间颜色、重置主题颜色、圆点大小
  - 「保存为主题」：命名后添加为自定义主题，出现在换主题菜单（当前主题不变）
- **天气**：天气开关、天气城市
- **课表 / 课程 / 铃声**：直接内嵌在设置面板里编辑（时段、假期、循环 / 学段科目 / 铃声文件与片段），
  每页底部有各自的「保存」按钮
  - 时段用滚轮/箭头选择时、分；保存时自动按时间排序，并检查结束晚于开始、时段不重叠

所有设置保存在 `config.json`，点「保存」立即生效。
设置面板底部还有「**恢复默认设置**」按钮，一键把颜色、圆点、人物、天气等设置重置为默认。

## 每日天气

窗口标题行显示今日天气和明天预报（数据来自 wttr.in，免费无需密钥，启动时和每 30 分钟自动更新）。
默认按网络 IP 定位城市，可在「设置 → 天气城市」里指定。

## 编辑课程

菜单 →「编辑课程…」按「学段 + 科目」选择：小学、初中、高中、大学各自有科目列表
（大学含高数、线代、大物、程序设计、马原等）。上课时倒计时上方会显示
「距离下课 · 语文」。

## 编辑铃声

菜单 →「编辑铃声…」可分别设置上课铃和下课铃：

- 选择本地音频文件（wav / mp3 / m4a / flac / ogg 等，非 wav 会自动用 ffmpeg 转码，首次稍慢）
- 设置片段「开始」「结束」秒数，两者之差就是播放时长
- 可点「试听」先听一遍

不设置则使用默认的 7 秒卡农。

## 主题

左上角图标或右键菜单 →「换主题」可切换，共 7 套：

| 主题 | 说明 |
| --- | --- |
| 深色 | 默认，深蓝黑卡片 |
| 浅色 | 白底黑字 |
| 海蓝 | 纯海蓝底 |
| 大肥鱼 · 满电 | 深海蓝底 + 大肥鱼全身立绘（深蓝背景融合）；左上铁盆，默认空盆、悬停变满盆 |
| 大肥鱼 · 节能 | 浅蓝底 + 铁锅头盔 Q 版立绘；左上铁盆同样空盆 → 满盆 |
| 丛雨 · 千恋万花 | 浅绿底，左侧绿发持刀立绘；左上武士刀，悬停刀身出鞘 |
| 芳乃 · 千恋万花 | 浅粉底，左侧白发全身立绘；左上小刀（五彩绳+樱花），悬停左倾、花瓣飞舞 |

动漫主题把完整人物立绘放在窗口左侧（白底已去除、与底色融合，无分隔缝），右侧显示倒计时等信息；
左上角的专属图案贴着整个窗口左上角，同时是菜单入口，鼠标悬停会切换成另一张图（空盆/拔刀/刀身左倾花瓣）。
顶部状态线使用各自主题色，状态圆点、进度条仍按上课/休息/假期变色。

动漫主题把完整人物立绘放在窗口左侧，向底色混合淡化一层，右侧显示倒计时等信息。
人物图原始素材在 `_img/cand/`，由 `build_assets.py` 缩放合成后生成 `assets/person_*.png`。
换图时替换对应文件并重跑该脚本即可。

## 课表规则（改 `config.json` 即可，右键「重新加载课表」生效）

- `daily_slots`：每天固定的上课时段。默认：
  - 07:40–11:30、14:00–16:00、16:30–18:30、19:00–21:30
- `holidays`：显式假期区间（`YYYY-MM-DD HH:MM`）。默认：
  - 2026-11-13 14:00 ~ 11-15 12:00（周五下午到周日上午）
  - 2026-11-22 14:00 ~ 11-26 00:00（23~25 会考）
- `cycle`：常规「上两周放一次假」规则——`anchor` 为恢复上课的时刻，
  从 anchor 起上 `teach_days` 天课，然后放 `rest_days` 天假，循环往复。
- `window.x / window.y`：窗口位置（拖动后自动写回）。

## 铃声

- 首次运行会自动合成 `canon_7s.wav`（7 秒卡农，C 大调，纯 Python 合成）。
- 上课开始、下课结束各响一次；假期不响。

## 文件

- `main.py` 界面与主循环
- `schedule.py` 课表 / 假期 / 倒计时逻辑
- `sound.py` 卡农合成与播放
- `config.json` 配置（含当前主题）
- `run.bat` 启动脚本
- `assets/` 人物立绘（`person_*.png`）与左上角图标（`icon_*.png`）
- `build_assets.py` 由原始人物图生成左侧立绘
